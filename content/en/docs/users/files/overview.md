Files opens on **Recent**, which groups everything you have opened by day. Tabs across the top switch between Recent, Cloud, Documents and Downloads.

![Files showing recent documents and folders in grid view](/screenshots/files-light.webp "Files in grid view, sorted by last opened."){width=1920 height=1200}

## Views and sorting

- Toggle between grid and list view with the buttons on the right of the toolbar.
- Sort by **Last opened**, **Name**, **Size** or **Type**.
- Press `Ctrl` + `F` to search the current location.

## Dark appearance

![Files in the dark appearance](/screenshots/files-dark.webp "Files follows the system appearance."){width=1920 height=1200}

:::shortcuts
- `Ctrl` `N` — New window
- `Ctrl` `Shift` `N` — New folder
- `Ctrl` `L` — Type a location
- `Space` — Quick preview
:::
