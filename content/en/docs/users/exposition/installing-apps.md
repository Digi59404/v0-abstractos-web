Exposition is the app store. Every app is sandboxed and updates in the background.

![Exposition showing featured apps and categories](/screenshots/exposition.webp){width=1920 height=1200}

:::steps

### Find an app

Browse **Featured** and categories, or search from the toolbar.

### Install

Select **Get** on the app page. Permissions the app may request are listed before you install.

### Update

Updates install automatically. Check **Updates** to see what changed.

:::

## From the command line

```bash
abstract-apps search scriblr
abstract-apps install app.scriblr.Scriblr
abstract-apps update --all
```
