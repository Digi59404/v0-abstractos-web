Settings groups every system option into panels. On a phone, panels open full screen; on tablet and desktop the panel list stays visible on the left.

## Panels

| Panel | What it controls |
| --- | --- |
| Network | Wi‑Fi, mobile data, VPN and hotspot |
| Display | Resolution, scaling, night light and multiple monitors |
| Sound | Output and input devices, per-app volume |
| Privacy & Security | App permissions, location, camera and screen lock |
| Accounts | Users, online accounts and sync |
| About | Device information and system updates |

:::tip
Start typing anywhere in Settings to search. Searching for `dark` jumps straight to the appearance option.
:::

## Opening Settings from the terminal

```bash
abstract-settings display        # open a specific panel
abstract-settings --search wifi  # open with a search
```
